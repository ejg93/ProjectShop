# 0002. Spring Boot 4.1, Java 25로 간다

- 날짜: 2026-08-03
- 상태: 채택

## 결정

백엔드를 Spring Boot 4.1.0 + Java 25 + Gradle(Kotlin DSL)로 만든다.
Gradle 툴체인에 Java 25를 못박아서 빌드를 돌리는 JDK와 무관하게 컴파일 대상이 고정된다.

## 저울질한 것

Boot 3.5는 자료가 훨씬 많고 실무에서 아직 이쪽을 많이 쓴다.
Boot 4는 Spring Security 7을 끌고 오는데, 권한 설정 API가 3.x 시절 예제와 달라서 검색한 코드가 그대로 안 붙는다.

그럼에도 4를 고른 이유는 이 프로젝트가 납품물이 아니라 학습용이고,
설정을 남의 예제에서 베끼는 대신 문서를 보고 직접 쓰는 편이 권한 체계를 익히는 목적에 맞기 때문이다.
로컬 실행만 하므로 운영 리스크도 없다.

## 따라오는 제약

- Security 설정은 람다 DSL만 쓴다. 3.x 예제의 체이닝 방식은 컴파일이 안 된다
- 스타터 이름이 갈렸다. 웹은 `spring-boot-starter-webmvc`, 테스트는 모듈별 `*-test` 스타터를 쓴다
- 로컬 `JAVA_HOME` 이 JDK 17 미만이면 Gradle 자체가 안 뜬다. 이건 저장소가 아니라 실행 환경 문제라 README에 적었다
